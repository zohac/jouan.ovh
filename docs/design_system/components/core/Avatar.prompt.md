**Avatar** — round profile image or initials fallback; optional orange ring and green availability dot. Used for Simon's portrait in the hero, header, and article bylines.

```jsx
<Avatar src="/assets/brand/portrait.jpeg" alt="Simon Jouan" size="xl" ring />
<Avatar initials="SJ" size="sm" />
```

Sizes: `sm` 32 / `md` 44 / `lg` 64 / `xl` 96. `ring` adds the accent ring.
