**Badge** — compact status or category label; soft fills drawn from the terminal/syntax palette. Use for states (`En ligne`, `Brouillon`), counts, or tech tags inline with a title.

```jsx
<Badge tone="success" dot>Disponible</Badge>
<Badge tone="accent">WordPress</Badge>
<Badge tone="info">Nest.js</Badge>
```

Tones: `neutral` / `accent` / `success` / `warning` / `danger` / `info`. `dot` adds a leading status dot.
