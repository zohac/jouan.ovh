## 2. Analyse approfondie des stories (patterns transverses)

1. **Diagnostic `backdrop-filter` digne d'un manuel (8.1).** Le blur du corps ne rendait pas — pas une valeur fausse, un piège de *backdrop root* : le `<header>` filtré (`blur(10px)`) confinait le `backdrop-filter` du descendant. Confirmé **empiriquement** (déplacement DOM → blur visible), réglé par `<Teleport to="body">`. Effet de bord attrapé : le Teleport change le bloc conteneur → régression de positionnement **page scrollée** + drag faussé → fix `position: fixed`. Invisible à la revue de code aveugle, vu **au navigateur**. Tracé en mémoire projet.

2. **Écart spec ↔ code réel capturé, pas subi (8.2).** L'AC d'epics et le UI kit listaient `skills`/`projets`/`contact`/`clear` ; ces commandes **n'existaient pas** dans le code Vue. Inventaire honnête (tableau commande par commande), puis **décision PO d'ajouter** pour aligner CAP-10 (et non requalifier l'AC en « préservation seule »). NFR9 préservé (aucune commande existante touchée : `helloWorld`/`new`/`system-info` intactes).

3. **Différé de revue → source unique, immédiatement (8.2).** La duplication des données (skills/projets/contact/email/ville) consolidée dans **`app/data/site.ts`** (`SITE.profile`/`skills`/`projects`, typés), branchée sur **9 surfaces** (4 programmes terminal + `index.vue` + `about.vue` + `contact.vue` + `Footer`). Rendu vérifié **identique**. Solde *en plus* le différé « contact inline » de la revue 7.2. Décision Simon : approche DRY/SOLID, zéro dette.

4. **Migration la plus risquée, prouvée constante (8.3).** Composant *stateful* + DOM-lourd (drag/resize), **sans filet de test**. Réécriture mécanique à comportement constant, garantie par un **tableau d'invariants avant/après** (`help`=9, drag Δ100/80 → 100/80, XSS échappé, close → `display:none`, ouverture header **et** `/contact`). Seul vrai piège `<script setup>` capturé : **`defineExpose({ createNewTerminal })`** sur le manager (sinon `undefined` côté ref du header).

5. **« Zéro dette » réaffirmé — 7ᵉ épic d'affilée.** Findings soldés à chaque story ; les différés sont des généralisations DS-wide délibérément regroupées (a11y/SEO/légal/déploiement), pas de la dette laissée dans l'épic.
