# Revue éditoriale — prose

Périmètre : `prd.md` et `addendum.md`. Le frontmatter, les syntaxes Markdown et les titres de sources sont exclus. Les termes de contrat entre backticks sont conservés lorsqu'ils identifient un champ, un fichier ou une commande. La revue porte uniquement sur la clarté, la cohérence, la grammaire, le mélange français/anglais et la compréhension ; les décisions de produit ne sont pas remises en cause.
