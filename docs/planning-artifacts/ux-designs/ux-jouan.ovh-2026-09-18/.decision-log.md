# UX Decision Log — jouan.ovh Light / Dark Mode

- **2026-09-18 — Cadrage initial & Arbitrages Simon** :
  1. **Sources intégrées** : `AGENTS.md`, `docs/project-context.md`, `docs/specs/spec-repositionnement-ia/SPEC.md`, `docs/design_system/tokens/colors.css`, `docs/design_system/ui_kits/jouan-site/Home - Awwwards.html`.
  2. **Direction artistique thème clair** : Option 1 « Papier technique / Crème solaire » retenue. Fond de page ivoire/sable chaud (`hsl(38 25% 97%)`), encres aubergine profonde (`hsl(320 30% 12%)`), accent orange Ubuntu adapté au contraste WCAG AA, bordures douces et chaleureuses.
  3. **Sanctuarisation du terminal** : Le Terminal Hero (`HomeHeroTerminal`) et les fenêtres CLI flottantes (`TerminalComponent`, `TerminalWindow`) restent **strictement sombres** (`--bg-terminal: var(--aubergine-deep)`), préservant l'effet machine / terminal sur page claire.
  4. **Composant ThemeToggle** :
     - Bouton compact, icône SVG vectorielle inline (`<ZIcon>`), 0 emoji.
     - Positionné immédiatement à gauche du badge d'état « Disponible » dans le dock d'état du header (`hdr__dock-right`) et dans le tiroir mobile (`hdr__menu-status`).
     - Cycle ternaire : `Système (auto) → Sombre (dark) → Clair (light) → Système (auto)`.
     - Info-bulle / `aria-label` dynamique indiquant le statut effectif et la prochaine action.
  5. **Comportement & Persistance** :
     - Écoute réactive de `prefers-color-scheme` en mode système.
     - Clé `localStorage` dédiée (`jouan-theme-mode`).
     - Prévention anti-FOUC par injection d'un script inline d'initialisation sur `document.documentElement` (`data-theme="light|dark"`).
  6. **Mode de travail** : Fast path retenu avec formalisation directe des deux contrats `DESIGN.md` et `EXPERIENCE.md`.
